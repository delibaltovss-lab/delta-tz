# Как подключить Codex к GitHub DELTA

1. Открой Codex в ChatGPT или на https://chatgpt.com/codex.
2. Выбери создание нового облачного окружения (Cloud environment).
3. В списке репозиториев найди `delibaltovss-lab/delta-tz`.
4. Если репозитория нет, разреши GitHub-доступ для Codex к этому репозиторию (авторизация Codex и ChatGPT GitHub могут отличаться).
5. Создай окружение. Установку зависимостей можно выполнить командой `python -m pip install -r requirements.txt`.
6. Для первой задачи: «Прочитай AGENTS.md и проверь бэктестер стратегии “Матрёшка”; не меняй торговые параметры без согласования. Создай PR с тестами».

Репозиторий сейчас **публичный**. Не добавляй ключи доступа, файлы .env и приватные данные.

Важно: автоматическое обновление VPS — отдельная настройка Git/SSH, подключения Codex самого по себе недостаточно.
