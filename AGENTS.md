# DELTA — инструкции для Codex

Проект: исследовательская стратегия «Матрёшка», без реальной торговли.

## Неизменяемые условия
- Тренд 1M → вход 1W.
- Тренд 1W → вход 1D.
- Тренд 4H → вход 1H.
- Тренд 1H → вход 15m.
- Первоначальный стоп: 1,5 × ATR(14) таймфрейма входа.
- Риск на сделку: $2 в базовом бэктесте.
- BTC, ETH, SOL, история за три года.
- Сравнение выходов RR 1:2, пробой трендовой линии, ATR-трейлинг.

## Требования к коду
- Не использовать будущие свечи, pivots доступны только после подтверждения.
- Учитывать комиссии и проскальзывание, явно отмечать, если funding не учтён.
- Не подключать реальные счета, не отправлять ордера, не хранить API-ключи.
- Проверять код тестами перед PR.
- Не сообщать о прибыльности до реального исторического расчёта.
