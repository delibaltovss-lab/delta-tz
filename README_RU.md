# DELTA «Матрёшка»: методика исследования

Это исследовательский бэктестер, не торговый бот. Не размещает ордера и не использует API-ключи.

## Торговая идея
Четыре независимых связки: месяц → неделя; неделя → день; 4H → 1H; 1H → 15m.
На старшем ТФ подтверждаем растущую поддержку (пары повышающихся pivot low) либо нисходящее сопротивление (пары понижающихся pivot high). На младшем ищем отскок и входим на открытии следующей свечи.

Начальный стоп = 1,5 × ATR(14) таймфрейма входа; ATR берём с уже закрытой сигнальной свечи. Исследовательский риск $2/сделка.

Сравниваем три независимых типа выхода:
- `rr2` — тейк на +2R;
- `trend_break` — закрытие при пробое линии;
- `atr_trail` — трейлинг 1,5 ATR.

Базовые символы: BTCUSDT, ETHUSDT, SOLUSDT. Пары таймфреймов × монеты × типы выхода = 36 комбинаций.

## Предположения и ограничения
- История: Binance USD-M futures 15m, затем ресемплинг.
- Pivot известен только через 2 свечи справа. Верхние свечи известны после полного закрытия.
- Комиссия по умолчанию 0,05% с каждой стороны, проскальзывание 0,02% с каждой стороны.
- Фандинг не моделируется; гэпы, лимиты ликвидности и реальное исполнение требуют отдельной проверки.
- Внутри свечи при достижении и SL, и TP приоритет имеет SL.
- Одна позиция одновременно на комбинацию инструмента, ТФ и режима выхода.
- Результаты синтетических тестов не доказывают прибыльность.

```bash
source .venv/bin/activate
pip install -r requirements.txt
python test_offline.py
python backtest.py --out results
```
